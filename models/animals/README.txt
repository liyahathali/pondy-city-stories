DROP-IN REALISTIC ANIMALS
=========================
Put rigged, animated .glb / .gltf animal models here and the game uses them instead of the built-in ones.
Name each file after the animal it replaces (anything after an underscore is ignored):

  dog_labrador.glb   dog_street.glb   cat_persian.glb   cow.glb   bull_kangayam.glb
  goat.glb           crow.glb         pigeon.glb

* The game scales, turns and centres each model automatically (add _rev if it faces backwards).
* Animation clips are picked by name: walk / trot, run / gallop, idle / stand, eat / graze, sit, lie / sleep, fly.
* Compressed (Draco / Meshopt) files are supported.
After adding files, restart start-windows.bat and press Ctrl+F5 in the browser.
