DROP-IN REALISTIC CHARACTERS
============================
Put Mixamo-rigged characters here (.fbx or .glb). The game gives them real walk / run / idle
animation automatically and uses them for the nearby people and the player.

* File names containing female / woman / girl / lady become women, everything else men.
* Free source: mixamo.com (free Adobe account) -> Characters -> pick a person ->
  Download -> Format: FBX Binary, Pose: T-pose. Save the .fbx file in this folder.
After adding files, restart start-windows.bat and press Ctrl+F5 in the browser.
